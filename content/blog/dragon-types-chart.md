# Dragon Types Chart

The fastest way to read a **Dragon types chart** is to separate the Dragon type from the second type. Dragon Pokémon are not all weak to the same moves: a Dragon/Flying Pokémon and a Dragon/Steel Pokémon inherit different defensive matchups.

## Dragon type matchup at a glance

| Question | Answer for a pure Dragon defender or attacker |
| --- | --- |
| Dragon's weaknesses | Ice, Dragon, Fairy |
| Dragon's resistances | Fire, Water, Electric, Grass |
| Dragon's immunities | None from the Dragon type alone |
| Dragon attacks are strong against | Dragon |
| Dragon attacks are resisted by | Steel |
| Dragon attacks do not affect | Fairy |

These are the standard main-series type interactions. A dual type can add, remove, or multiply the result, so use the complete [Pokémon type chart](/pokemon/type-chart) before choosing a move.

## The three checks to make before using a Dragon counter

### 1. Check the second type

Start with the row in the table, not just the word “Dragon.” For example, Dragon/Flying, Dragon/Ground, and Dragon/Steel do not share the same defensive profile. The second type can create an immunity or add a new weakness.

### 2. Check whether the move is really Ice, Dragon, or Fairy

The Dragon type's cleanest weaknesses are Ice, Dragon, and Fairy. A move's displayed type matters more than the Pokémon's species name. If the move is not one of those types, check the full chart instead of assuming it will deal super-effective damage.

### 3. Check the exact combination in the calculator

Open the [type calculator](/calculator), select the defending Pokémon's two types, and then compare the attacking type. This catches the cases where two type multipliers combine into a result that is different from the pure Dragon row.

## Dragon type chart takeaway

Dragon is strong against Dragon but cannot hit Fairy at all, while pure Dragon defenders are weak to Ice, Dragon, and Fairy. The second type is the part that makes each Dragon matchup different. Use the grouped list above to identify the pairing, then verify the exact multiplier in the chart before building a team or choosing a counter.
