# Pokémon Counter Chart

Use this **Pokémon counter chart** to find a type that hits the defender for super-effective damage. Start with the defender's type, choose one of the attacking types in the right column, and then check the full dual-type matchup before choosing a specific Pokémon.

This is a type-level reference for the standard main-series chart. It is not a claim that one species is always the best counter. Check the complete [Pokémon type chart](/pokemon/type-chart) for the underlying multipliers.

## How to use the counter chart against a dual type

### 1. Write down both defending types

Do not stop after finding the first type. A Water/Ground defender is not handled like pure Water, and a Dragon/Flying defender is not handled like pure Dragon. The second type can add a weakness, remove one, or change the multiplier.

### 2. Keep only attacks that remain effective

Compare the candidate attacking types against both defensive types. A type that is super effective against one half can be resisted by the other half. The calculator is useful here because it combines the two multipliers instead of making you remember them separately.

### 3. Check abilities and battle rules

Abilities, held items, Terastallization, special forms, and game-specific rules can change the result. Treat the table as the type baseline, then confirm the exact Pokémon and format before committing to a move.

## Counter chart versus counter Pokémon

The chart answers **which attack types to test first**. A counter Pokémon also needs the right move, speed or bulk, ability interaction, and role on the rest of the team. That is why a universal list of “best counter Pokémon” is less reliable than starting with the type matchup.

For a quick matchup, open the [type calculator](/calculator), enter one or two defending types, and compare the attacking rows. For team planning, use the [team calculator](/pokemon/team-calculator) after the type-level shortlist is clear.

## Pokémon counter chart takeaway

Use the defender's type as the entry point, choose a super-effective attacking type from the table, and then verify the full dual-type and ability context. That three-step process turns the chart into a practical counter shortlist without confusing a type advantage with a universal Pokémon ranking.
