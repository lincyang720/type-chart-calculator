## Fetching Scales for Feebas: official event details

Nintendo's official announcement says **Feebas and Milotic are coming to town** during the *Fetching Scales for Feebas* event in Pokémon Pokopia. The event runs from **August 13 at 5:00 a.m. to August 28 at 4:59 a.m. local time**. During that window, players can collect the event-only **Prism Scales**, befriend Feebas and Milotic, and exchange the scales for seaside-themed furniture and other items.

The event instructions and timing below come from [Nintendo's official event announcement](https://www.nintendo.com/us/whatsnew/join-the-fetching-scales-for-feebas-event-in-pokemon-pokopia/). The type-matchup section is a separate TypeMatchup explanation based on the standard Pokémon type chart.

### How to start the event

Nintendo says that the following conditions are required:

1. Update Pokémon Pokopia to **version 2.0.0**.
2. Complete a town's important requests and rebuild the Pokémon Center.
3. Set the Nintendo Switch 2 system's date and time to the current real-world date and time.
4. Launch the game while connected to the internet.

Once it is active, speak to Feebas near the Pokémon Center. A Dream Island accessed through a doll can be used to collect Prism Scales, and the Pokémon Center is where the scales are exchanged for event items.

### Important official limitations

- The event does not occur on Cloud Islands or in Bubbly Basin.
- Pokémon befriended during the event remain in town after the event ends.
- The system needs an internet connection the first time the event is played.
- For Link Play, Nintendo directs players to use Palette Town; the event cannot be played in Spectator Mode.

## Feebas and Milotic type matchups: TypeMatchup's standard-chart reference

The official [Pokémon Pokédex entry for Milotic](https://www.pokemon.com/us/pokedex/milotic) identifies **Milotic and its pre-Evolution Feebas as Water type** and lists **Grass** and **Electric** as their weaknesses. On the standard Pokémon type chart, that means a Grass- or Electric-type attack is super effective against a pure Water-type defender.

This is a **standard type-chart reference, not a claim about a Pokopia-only battle mechanic**. Nintendo's event announcement explains collecting Prism Scales and befriending Pokémon; it does not state that the event uses combat encounters or modifies type effectiveness. Check the in-game event details before treating a standard weakness as an event strategy.
