# Type Chart Dataset

Open, machine-readable exports of the Pokemon type-effectiveness rules for
**Generation 6–9** (the current 18-type system, including Fairy).

Everything here is generated by `generate.py` from this repository's own canonical
`../data/typeChart.json`, so these exports can never drift from what the site serves.

## Files

| File | Description |
|------|-------------|
| `type-chart.csv` | The full 18×18 effectiveness matrix. Rows = defending type, columns = attacking type, cell = damage multiplier. |
| `dual-type-combinations.json` | Every single type (18) and dual-type combination (153) with its defensive summary: 4× / 2× / 0.5× / 0.25× / 0× attacking types. |
| `index.html` | A standalone calculator — open it in any browser, no dependencies, no build step. |
| `typecalc.py` | A command-line calculator: `python3 typecalc.py fire flying`. |
| `generate.py` | Regenerates the CSV and JSON from `../data/typeChart.json`. |

## Usage

```bash
python3 generate.py              # regenerate the exports
python3 typecalc.py fire flying  # quick lookup
```

```python
import json
data = json.load(open("dual-type-combinations.json"))
print(data["combinations"]["fire-flying"]["defensive"])
```

## Accuracy

The matrix encodes the official type-effectiveness rules: Fairy was introduced in
Generation 6 and there have been no type-chart changes through Generation 9.
Every dual-type summary is computed by `generate.py` rather than hand-written, so
4× always means two stacked 2× weaknesses and 0× always means an immunity.
